## Multi - Tenant Application

This is a multi-tenant application that allows multiple tenants to use the same application while keeping their data isolated. Each tenant has its own blog and can manage their own content independently. The application is designed to support multiple custom domain blogs for each tenant, allowing them to have a unique online presence.

#### Built while learning the following technologies:
- **Next.js**: A React framework for building server-side rendered applications.
- **Clerk**: A user management platform for authentication and authorization.
- **Drizzle ORM**: An ORM for TypeScript and JavaScript that provides a type-safe way to interact with databases.
- **Docker**: A platform for developing, shipping, and running applications in containers.
